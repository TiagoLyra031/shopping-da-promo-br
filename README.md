# 🛍️ Shopping da Promo BR

### Encontre o que procura. Pague menos!

O **Shopping da Promo BR** é uma página de divulgação de ofertas, descontos e promoções de produtos encontrados em lojas online.

O objetivo é facilitar o acesso dos consumidores a oportunidades de economia, reunindo ofertas e direcionando os visitantes para nossos canais oficiais.

## 🚀 Sobre o projeto

Este projeto consiste em uma landing page responsiva, desenvolvida para receber visitantes de campanhas digitais, especialmente do Pinterest.

A página permite que os usuários escolham onde desejam acompanhar nossas ofertas:

- **WhatsApp:** canal de divulgação de promoções.
- **Telegram:** comunidade de ofertas e descontos.

## ✨ Funcionalidades

- Interface moderna com identidade visual azul-marinho.
- Layout responsivo para celulares, tablets e computadores.
- Botões de acesso ao WhatsApp e Telegram.
- Estrutura preparada para integração com o Pinterest Tag.
- Navegação simples e intuitiva.
- Página estática, sem necessidade de banco de dados.

## 💻 Tecnologias utilizadas

- HTML5 — estrutura da página.
- CSS3 — estilização e responsividade.
- JavaScript — interatividade e eventos de rastreamento.
- GitHub Pages — hospedagem gratuita.

## 📊 Marketing e monitoramento

O projeto foi preparado para permitir a integração com o Pinterest Tag, possibilitando o acompanhamento de cliques nos botões de acesso aos canais.

**Importante:** para ativar o rastreamento, é necessário configurar o ID real da Pinterest Tag no código.

Os eventos de clique não representam necessariamente novos inscritos nos canais.

## 🌐 Publicação

A página pode ser publicada gratuitamente utilizando o GitHub Pages.

Para publicar:

1. Envie o arquivo `index.html` ao repositório.
2. Acesse Settings → Pages.
3. Selecione Deploy from a branch.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação.

## ⚠️ Aviso

O Shopping da Promo BR divulga ofertas e pode utilizar links de afiliados.

Preços, descontos, disponibilidade e condições de compra são definidos pelas lojas responsáveis e podem sofrer alterações sem aviso prévio.
